\begin{abstract}
The quantum approximate optimization algorithm (QAOA) provides a controlled way to interpolate between shallow, local quantum circuits and deeper variational circuits whose classical simulation becomes increasingly expensive. For MaxCut on random 3-regular graphs, this interpolation is especially informative: the graph ensemble has bounded degree and locally tree-like structure, yet typical instances exhibit enough global frustration to expose a practical tension between circuit depth, optimizer cost, classical baselines, and achievable approximation ratio. \section{Introduction}

Combinatorial optimization is a natural setting in which to examine the practical boundary between quantum and classical computation. Variational quantum algorithms turn an optimization problem into a parameterized family of quantum states, with a classical outer loop used to choose circuit parameters. The quantum approximate optimization algorithm (QAOA) is the canonical example for binary constraint satisfaction problems because it has a simple alternating structure, admits rigorous analysis at low depth, and connects continuously to adiabatic evolution as the number of layers grows \cite{Farhi2014QAOA,Farhi2019QAOAReview,Hadfield2019QAOA}. Its performance, however, is not specified by circuit depth alone. Approximation quality depends jointly on depth, graph structure, parameter initialization, optimizer budget, noise, finite-size effects, and the strength of the classical comparator.

This paper focuses on MaxCut for random 3-regular graphs. Given a graph $G=(V,E)$ with $n=|V|$ vertices and $m=|E|=3n/2$ edges, the MaxCut objective is
\begin{equation}
  C(z)=\sum_{(i,j)\in E}\frac{1-z_i z_j}{2},
  \qquad z_i\in\{-1,+1\}.
\end{equation}
The approximation ratio of a candidate distribution is the expected cut value divided by the exact optimum,
\begin{equation}
  \rho=\frac{\E[C]}{C_{\max}},
  \qquad
  C_{\max}=\max_z C(z).
\end{equation}
Random 3-regular graphs are sparse, bounded-degree, and locally tree-like at small radii, which makes them amenable to local-algorithm analysis. At the same time, their typical MaxCut landscapes are nontrivial enough that shallow local structure is not the whole story \cite{Dembo2017MaxCutRandomRegular,Montanari2019OptimizationRandomGraphs,Brandao2022LocalAlgorithms}. This combination makes the ensemble a useful test bed for separating depth-limited QAOA behavior from finite-size and optimizer artifacts.

The phrase quantum--classical phase boundary is used here operationally rather than as a claim of a thermodynamic phase transition. We define the boundary as the region in $(n,p)$ where three conditions are simultaneously met:
\begin{enumerate}[label=(\roman*)]
\item exact or high-fidelity classical simulation is still feasible for a statistically meaningful calibration set;
\item simulation cost is high enough that the simulator cannot be treated as an inexpensive optimizer oracle at the target scale;
\item the QAOA circuit depth is large enough that performance is no longer captured solely by radius-$p$ tree neighborhoods.
\end{enumerate}
This definition is deliberately empirical. It is intended to identify where controlled benchmarking remains possible while also reflecting the onset of the resource tensions that motivate quantum experiments.

The central question is how approximation ratio changes as one spends QAOA depth in this boundary regime. A useful answer should not report only the best ratio at the largest simulated depth. It should also quantify the marginal gain per layer, the optimizer effort required to realize that gain, the degree to which parameters transfer across graph instances, and the point at which named classical baselines remain competitive. We therefore organize the study around four measurable trade-offs:
\begin{enumerate}[label=(\roman*)]
\item the ensemble-averaged function $\rho(p,n)$ and its finite-size drift;
\item the marginal improvement $\Delta_p=\rho(p,n)-\rho(p-1,n)$;
\item the optimizer and sampling cost required to certify each improvement;
\item the gap to exact, heuristic, and local classical baselines.
\end{enumerate}

Several prior results constrain what should be expected. At fixed depth, QAOA is a local algorithm on bounded-degree graphs: the value of an edge depends only on the subgraph in a radius-$p$ neighborhood around that edge \cite{Farhi2014QAOA,Brandao2022LocalAlgorithms}. For random regular graphs, these neighborhoods are tree-like with high probability when $p$ is small compared with $\log n$, so low-depth performance can concentrate strongly across instances \cite{Wormald1999RandomRegular,Dembo2017MaxCutRandomRegular}. Conversely, increasing $p$ increases both expressive power and classical simulation difficulty. Exact statevector simulation scales as $O(2^n)$ in memory, while general tensor-network contraction is sensitive to depth and graph expansion \cite{Markov2008Simulation,Gray2021HyperOptimizedContraction}. These facts motivate a careful depth-resolved analysis rather than a single-depth benchmark.

\section{Discussion}

The measured depth--ratio curve should be read as a resource trade-off, not as a single performance number. In the calibrated boundary regime, increasing $p$ improves or preserves the globally optimized QAOA value in principle, because an added layer can be made trivial. In practice, the realized value depends on whether the classical outer loop can find useful parameters and whether the cost of doing so is included in the benchmark. This distinction matters most near the quantum--classical boundary: deeper circuits are precisely where simulation and optimization become expensive enough that exhaustive parameter search is no longer a neutral diagnostic.

The random 3-regular ensemble clarifies this issue. At very low depth, QAOA behaves like a local algorithm. Its expected contribution per edge is controlled by a bounded-radius neighborhood, and random regular graphs locally resemble trees. In this regime, instance concentration is expected and transfer parameters may work well. At larger depth, the circuit can probe cycles, long-range correlations, and global constraints, but classical simulation and optimizer costs rise. The boundary region is therefore where the local-algorithm picture begins to lose explanatory completeness while exact benchmarking has not yet disappeared.

The comparison with named classical baselines is central. A QAOA curve that improves monotonically with depth may still lie below simple classical heuristics. Conversely, a curve that approaches or exceeds a particular baseline at calibrated depth does not imply broad quantum advantage unless the baseline suite and resource accounting are sufficiently strong. The final manuscript should therefore state the comparator precisely. For example, a claim relative to Goemans--Williamson rounding is different from a claim relative to multi-start local improvement, message-passing heuristics, or problem-specific branch-and-cut. This draft avoids the phrase ``state-of-the-art'' unless a specific named method and implementation are supplied.

Several limitations should remain visible after the placeholders are filled. First, the simulations are noiseless unless hardware data are inserted. Noise can change the apparent optimal depth by making deeper circuits worse despite greater variational expressivity. Second, the exact normalization by $C_{\max}$ restricts the largest graph sizes unless exact optima are available from a reliable solver. Third, optimizer budget is an algorithmic resource. Reporting only the best value over many restarts can overstate practical performance if the number of evaluations is not included. Fourth, the operational boundary depends on the simulator, contraction strategy, hardware, and implementation details used for calibration.

The most useful interpretation of this study is therefore conditional and reproducible. Given a graph ensemble, a simulator, an optimizer budget, and a named baseline suite, the data specify how much approximation ratio is purchased by each additional QAOA layer. If the audited results show that layer gains persist near the boundary, the result motivates larger simulations or hardware experiments with the same instance distribution. If the gains saturate before QAOA reaches the selected baseline, the result is still informative: it identifies the depth scale at which this ansatz and optimizer cease to be competitive under the chosen resource model.

Future work should extend the same protocol in three directions. First, the boundary definition can be repeated for noisy circuit models and hardware-native compilation. Second, the random 3-regular ensemble can be compared with planted, weighted, or higher-degree graph families to test whether transfer schedules survive changes in local statistics. Third, the optimizer protocol can be replaced by differentiable, layerwise, or learning-based methods to determine whether the observed trade-off is an ansatz limitation or an outer-loop limitation \cite{Zhou2020QAOAParameters,Wurtz2021QAOATraining,Author2024Optimizer}.

The cost Hamiltonian is
\begin{equation}
  H_C=\sum_{(i,j)\in E}\frac{I-Z_iZ_j}{2},
\end{equation}
where $Z_i$ denotes the Pauli $Z$ operator on vertex $i$. The mixer Hamiltonian is
\begin{equation}
  H_B=\sum_{i=1}^{n}X_i.
\end{equation}
The QAOA state at depth $p$ is
\begin{equation}
  \ket{\psi_p(\boldsymbol{\gamma},\boldsymbol{\beta})}
  =
  \left[
  \prod_{\ell=1}^{p}
  e^{-i\beta_\ell H_B}
  e^{-i\gamma_\ell H_C}
  \right]\ket{+}^{\otimes n}.
\end{equation}
The objective optimized by the classical outer loop is
\begin{equation}
  F_G(\boldsymbol{\gamma},\boldsymbol{\beta})
  =
  \bra{\psi_p(\boldsymbol{\gamma},\boldsymbol{\beta})}
  H_C
  \ket{\psi_p(\boldsymbol{\gamma},\boldsymbol{\beta})}.
\end{equation}
For each instance $G$, the reported QAOA ratio is
\begin{equation}
  \rho_G(p)=
  \frac{\max_{\boldsymbol{\gamma},\boldsymbol{\beta}}F_G(\boldsymbol{\gamma},\boldsymbol{\beta})}
  {C_{\max}(G)},
\end{equation}
where the maximum is replaced in practice by the best value certified under the stated optimizer budget.

\subsection{QAOA simulation}

The primary simulations use \texttt{<INSERT SIMULATOR NAME>} in exact statevector mode. The statevector is initialized as $\ket{+}^{\otimes n}$, cost phases are applied in the computational basis, and mixer phases are applied as tensor products of single-qubit $X$ rotations. QuTiP is not the fastest available backend for large QAOA simulations, but it provides transparent operator construction and is useful for small-instance reproducibility.

\begin{lstlisting}[language=Python,caption={Minimal QuTiP reference skeleton for a small MaxCut QAOA expectation. This code is intended for validation, not large-scale simulation.}]
import numpy as np
from qutip import basis, qeye, sigmax, sigmaz, tensor

def op_on_site(op, site, n):
    ops = [qeye(2) for _ in range(n)]
    ops[site] = op
    return tensor(ops)

def qaoa_expectation_qutip(n, edges, gammas, betas):
    plus = (basis(2, 0) + basis(2, 1)).unit()
    psi = tensor([plus for _ in range(n)])

    xs = [op_on_site(sigmax(), i, n) for i in range(n)]
    zs = [op_on_site(sigmaz(), i, n) for i in range(n)]

    hc = 0
    for i, j in edges:
        hc = hc + 0.5 * (tensor([qeye(2) for _ in range(n)]) - zs[i] * zs[j])

    hb = sum(xs)

    for gamma, beta in zip(gammas, betas):
        psi = (-1j * gamma * hc).expm() * psi
        psi = (-1j * beta * hb).expm() * psi

    return np.real((psi.dag() * hc * psi)[0, 0])
\end{lstlisting}

All ensemble means are computed over graph instances.
